# inSuccess Team OS mobile

Expo SDK 57 / React Native native client for iOS and Android.

## Local setup

```bash
cp .env.example .env.local
npm ci
npx expo start
```

Set `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` in `.env.local`. Never add a Supabase secret or service-role key to this app.

The client signs in with Supabase Auth, persists the session with Expo SQLite, verifies an active row in `team_members`, and relies on the existing RLS policies for all data access.
